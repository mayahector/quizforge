# QuizForge

**QuizForge** is a professional quiz management platform built with Django. It lets
instructors build categorized quizzes with timed, multiple-choice questions, and
lets learners take quizzes, track their scores, and compete on a leaderboard.

> Full setup instructions, architecture notes, and API docs are added as the
> project matures — see the commit history for the build-out story.
